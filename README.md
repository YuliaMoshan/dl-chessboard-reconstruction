# Project 1 – Chessboard Square Classification and Board-State Reconstruction

This repository presents a complete computer vision pipeline for **reconstructing the full state of a chessboard from a single RGB image**.

The project addresses real-world challenges such as varying illumination, perspective distortions, visually similar pieces, and partial occlusions. It formulates the task as **independent square-level classification**, combined with explicit uncertainty handling and lightweight board-level reasoning.

This work was developed as a project for *Introduction to Deep Learning* course, and follows the instructions provided by the course staff. At the same time, the repository is designed to be understandable and reusable by external users interested in structured vision problems and uncertainty-aware prediction.

---

### Data Availability and Repository Contents

To balance reproducibility with repository size and cloning speed, this GitHub
repository includes a **fully executed version of the project** with derived
artifacts and results, while the **raw dataset** and **processed square-level data** are provided separately.

Included in this repository:
- Manually annotated occlusion frames (`data/occluded_frames/`)
- Intermediate CSV indices
- Inference results and visualizations (`results/`)

Provided via Google Drive:
- The original raw dataset (`data/csv_games/`)
- Processed square-level data (`cache/square_crops/`)
- The trained model checkpoint (`models/square_classifier.pt`)

This allows full inspection of the pipeline and outputs **without requiring the raw dataset download**.
For full reproducibility, all large artifacts (raw dataset, processed square-level data,
and trained model checkpoint) are provided via Google Drive.

CSV files must contain the following columns:

- `to_frame`

### 1. Raw Dataset (Original Format)

**Contents (zipped):**
```
csv_games/
  <game_id>/
    <game_id>.csv
    tagged_images/
      frame_000001.jpg
      frame_000002.jpg
      ...
```

**Installation instructions:**

1. Download the archive (e.g. `csv_games.zip`)
2. Place it at the **project root** (same level as `data/`)
3. Unzip into the existing `data/` directory:

```bash
unzip csv_games.zip -d data/
```

This will create:
```
data/csv_games/
```
alongside the existing `data/occluded_frames/`, without overwriting any files.

### 3. Preprocessed Square Crops (Required for Training and Batch Inference)

The extracted square-level crops are provided separately due to their size. 
These are **derived artifacts** generated by the preprocessing pipeline (scripts 01–03).

**Contents (zipped):**
```
cache/
  square_crops/
    <game_id>_<frame_id>_sq_00.jpg
    <game_id>_<frame_id>_sq_01.jpg
    ...
  square_crops_index.csv

```

**Installation instructions:**

1. Download the archive (e.g. `square_crops.zip`)
2. Place it at the **project root** (same level as `cache/`)
3. Unzip into the existing `cache/` directory:

```bash
unzip square_crops.zip -d cache/
```

This will recreate:

```
cache/square_crops/
```

Downloading these files allows: 
- retraining the model **without rerunning the full preprocessing pipeline**
- running batch inference
They are **not** required for single-image inference (script 07).

## Preprocessing Pipeline (Optional for full reproducibility)

The preprocessing pipeline constructs frame-level indices, expands FEN strings
into per-square labels, and extracts context-aware square crops.

If you wish to regenerate all derived artifacts from the raw dataset:

```bash
python scripts/01_build_csv_index.py
python scripts/02_fen_to_square_labels.py
python scripts/03_extract_square_crops.py
```

Generated artifacts:
- `cache/frames_index.csv`
- `cache/frames_with_square_labels.csv`
- `cache/square_crops/`
- `cache/square_crops_index.csv`

## Training the Square Classifier

```bash
python scripts/04_train_square_classifier.py
```

This will:
- Train a ConvNeXt-Tiny classifier
- Save the best model to `models/square_classifier.pt`
- Compute and save normalization statistics

---

## Batch Inference & Evaluation

Runs inference on a dataset split (default: `test`) and writes visual/CSV outputs.

```bash
python scripts/05_inference_and_fen_reconstruction.py --split test
```

Outputs:
- Square-level and board-level evaluation metrics
- Reconstructed board images with red **X** marking OOD squares
- Debug CSV files under `results/`

Optional visualization:

```bash
python scripts/06_visualize_frame_prediction.py
```

---

## Single Image Inference (Evaluation API)

Run inference on a single board image (RGB). Requires model artifacts in `models/`.

```bash
python scripts/07_infer_single_image.py --image-path path/to/image.jpg
```

Outputs:
- Reconstructed board image
- Side-by-side visualization
- Results saved under `results/`

## Notes

- The `cache/` is fully derived from the raw dataset and can be regenerated.
- For inference-only use, ensure the model checkpoint and metadata are present.
- If you encounter errors such as:
  ```
  undefined symbol: __kmpc_global_thread_num
  ```
  MKL / Intel OpenMP is still being loaded. Remove those packages and reinstall
  NumPy with OpenBLAS as described in `SETUP.md`.
